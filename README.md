## ✨ Features

- 🔒 **App-private storage** — invisible to other apps
- 📁 **Two vaults** — Personal and Professional
- 🖼️ **All file types** — images, videos, audio, PDFs, ZIPs
- 📸 **Secure camera** — captures straight into the vault
- 🔑 **PIN + Fingerprint** unlock
- 🗑️ **Recycle Bin** with restore
- 🚫 **Mandatory PIN for deletion** — no accidental data loss
- 🔍 **Search** across vaults
- 📊 **Storage dashboard** with risk alerts
- 📜 **Activity history**
- 💾 **Export backup** to device storage
- 🌐 **100% offline** — no cloud, no tracking, no ads

---

## ⚠️ Important

Nivo Vault is **local-only**. Your files exist only on your device.

If you:
- Uninstall the app → **files are deleted**
- Lose your phone → **files are lost**
- Reset your phone → **files are lost**

**Use Settings → Export Vault Backup regularly.**

## 🛠 Tech Stack

- **Language:** Kotlin
- **UI:** Material 3 + Custom Canvas drawing
- **Storage:** App-private filesystem
- **Security:** SHA-256 PIN hashing + BiometricPrompt
- **Min SDK:** Android 7.0 (API 24)
